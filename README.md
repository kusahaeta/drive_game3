# TURBO KART GP

ブラウザで動く 3D カートレースゲームです。プレイヤー 1 台＋NPC 7 台の計 8 台で 3 ラップを競います。

## 起動方法

ビルドは不要です。プロジェクトのフォルダで以下を実行し、`http://localhost:4173` を開いてください。

```bash
npm start
```

（中身は `python3 serve.py 4173` です。編集したファイルがすぐ反映されるようキャッシュを無効にしています。Three.js とフォントは初回に CDN から読み込みます）

## 操作

| キー | 動作 |
| --- | --- |
| `↑` / `W` | アクセル |
| `↓` / `S` | ブレーキ・バック |
| `←` `→` / `A` `D` | ハンドル |
| `Space` / `Shift` | ジャンプ・ドリフト（曲がりながら押し続ける） |
| `X` / `E` | アイテムを使う（`↓` を押しながらで後ろへ投げる） |
| `Esc` / `P` | ポーズ |
| `R` | リスタート |
| `M` | ミュート |

ゲームパッドにも対応しています（A: アクセル、B: ブレーキ、RB: ドリフト、LB/X: アイテム）。振動に対応したパッドでは、ぶつかったときや被弾したときに振動します。

## ゲームの要素

- **グランプリ**：タイトル画面でモードを「グランプリ」にしてカップを選ぶと、カップの 4 コースを連続で走ります。各レースの順位でポイント（1 位から 15 / 12 / 10 / 8 / 6 / 4 / 2 / 1）が入り、4 レースの合計で最終順位が決まります（同点なら最終レースで上だった方が上位）。レース後は全員のゴールを待ってからポイントを加算し、総合順位の順に並べ替えます（`Enter` で飛ばせます）
  - サンシャインカップ：サニーサーキット → シーサイドベイ → ジャングル遺跡 → スノーピーク
  - フレイムカップ：サニーサーキット → スターライトロード → ジャングル遺跡 → マグマキャッスル
  - スターカップ：シーサイドベイ → マグマキャッスル → スノーピーク → スターライトロード
  - サンダーカップ（上級者向け）：ジャングル遺跡 → スターライトロード → マグマキャッスル → サンダーキャニオン
  - カップは `src/tracks/cups.js` で追加・変更できます
- **ドリフトでダッシュ**：ドリフトを続けると火花が 青 → オレンジ → 紫 に変わり、離したときに段階に応じたダッシュが出ます
- **ロケットスタート**：カウントダウンの「1」でアクセルを押すとダッシュ。早く押しすぎるとエンストします
- **アイテム**：順位が低いほど強いアイテムが出やすくなります
  - ダッシュ / トリプルダッシュ / ゴールドダッシュ（7.5 秒間ダッシュし放題）
  - バナナ / トリプルバナナ / ニセボックス（アイテムボックスそっくりのわな。「?」が逆さま）
  - シェル（直進・壁で跳ね返る）/ ホーミング（1 つ前の順位の相手を追う）/ それぞれのトリプル版
  - トリプル系は使うまでカートのまわりを回り、飛んできたアイテムを 1 つ防ぎます。回っているシェル・バナナは当たった相手をスピンさせます
  - ボム：投げて（`↓` で後ろに置いて）しばらくすると爆発し、まわりを巻き込みます
  - トップシェル：空を飛んで 1 位を追いかけ、真上から落ちて爆発します（同時に 1 つまで）
  - ホーン：まわりのカートをスピンさせ、トップシェルを含む近くのアイテムを壊します
  - スミ：自分より前の全員の画面にスミをかけます（NPC はハンドルがふらつく）
  - スター：7 秒間無敵で少し速くなり、ダートでも減速せず、ぶつかった相手をスピンさせます
  - サンダー：自分以外の全員をスピンさせて小さくし、持っているアイテムをなくさせます。小さい間は遅く、普通の大きさのカートに踏まれるとスピンします（同時に 1 つまで）
  - ジェット：弾丸になってコースに沿って自動で突き進み、ぶつかった相手をはじき飛ばします
- **ダッシュ板・ダート**：オレンジの板で加速し、路肩のダートに入ると減速します
- **ジャンプとトリック**：ジャンプ台や谷越えで飛んでいる間に `Space` を押すとトリック（回転）し、着地でダッシュします
- **コース**（7 種類）
  - サニーサーキット：丘越えの大ジャンプ、川に架かる橋、山のトンネル、バンク付きのカーブ、壁のない海辺の崖道
  - ジャングル遺跡：密林の土の道、岩山の洞窟、台地の古代遺跡（石柱・石のアーチ・神殿）、川の谷越えジャンプ、木の吊り橋、川沿いの崖道
  - スノーピーク：つづら折りで雪山を登り、山頂のトンネルからスキージャンプで谷越え。崖沿いの下り、凍った湖岸のつるつる滑る道。雪が降り、丸太小屋や雪だるまも
  - マグマキャッスル：溶岩の海に浮かぶ岩の道と魔王の城。石橋と火の玉の坂を越え、北は「壁のある回り道」と「壁のない溶岩の上の近道」に分かれる。後半は城の中へ。城内は 2 本の大広間に分かれ、外回りはクラッシャー、城側はファイアバーが待つ
  - スターライトロード：宇宙に浮かぶ虹色の道。立体交差の 8 の字、柵のない区間、宇宙の裂け目ジャンプ
  - サンダーキャニオン（上級者向け）：峡谷の台地を駆ける細い道。両側が崖の尾根の S 字、バンク付きの連続ヘアピン、下り坂の裂け目ジャンプ、落石の降る谷底の橋、大岩が転がる登り、柵のない崖っぷち、台地を貫くトンネル。東側にはヘアピンと裂け目を飛ばせる、細くて壁のない近道（クラッシャー付き）がある
  - 谷や崖から落ちるとコース上に戻されます
- **分かれ道**：コースが分岐して合流する所があり、好きな方を選べます（NPC もルートを選びます）
- **邪魔してくる敵**：震えて予告してから落ちてくるクラッシャー、左右に往復する UFO、赤い印で予告して降ってくる隕石、坂を転がり落ちてくる大雪玉・大火の玉、回転するファイアバー。当たるとスピンします
- **凍った路面**：グリップが弱く、よく滑ります
- **手ごたえ**：被弾・壁や他のカートとの衝突・大ジャンプの着地・近くに落ちたクラッシャーや隕石で画面が揺れ、被弾すると画面のふちが赤く光ります。壁やカートにこすると火花が散り、着地でカートがつぶれ、ダッシュで伸びます。ドリフト中はカメラが曲がる側へ少し傾きます
- **NPC**：コースの内側を狙って走り、ドリフト、アイテムの使用、バナナよけを行います。むずかしさで速さと攻撃性が変わり、プレイヤーとの差に応じて速さが少し変わります（ラバーバンド）

## コースの追加方法

1. `src/tracks/` に新しいファイル（例 `beachLoop.js`）を作り、コース定義を `export default` する
2. `src/tracks/index.js` で import して `TRACKS` 配列に追加する

タイトル画面のコース選択に自動で表示されます。定義の最小例:

```js
export default {
  id: "beach-loop",
  name: "ビーチループ",
  description: "海沿いの高速コース",
  laps: 3,
  roadWidth: 18,
  points: [ [0, 0, 0], [0, 0, -120], [100, 6, -160], [180, 10, -60], [120, 2, 60] ], // [x, 高さ, z]
  itemBoxRows: [0.2, 0.6],                 // 周回に対する割合
  boostPads: [{ at: 0.33, lateral: 0 }],
  features: [
    { type: "ramp", at: 0.35, height: 2.4 },  // ジャンプ台
    { type: "gap", from: 0.36, to: 0.375 },   // その先の谷
    { type: "tunnel", from: 0.6, to: 0.68 },
    { type: "cliff", from: 0.8, to: 0.9, side: "right" },
  ],
  theme: { grass: ["#c9d98a", "#b8cc7a"], sand: "#f0e0a8", waterLevel: 0 }, // 色や地形の上書き
  scenery: { trees: 300, seed: 3 },
};
```

分かれ道は `branches` で作れます（分岐する位置 `from`・合流する位置 `to`・途中で通る点 `points`。壁なしや幅も指定可。例：`src/tracks/magmaCastle.js`）。

邪魔してくる敵は `hazards` で置けます（`crusher` / `ufo` / `meteor` / `snowball` / `firebar`）。溶岩と城の見た目は `theme.lava` / `theme.castle` と `scenery.castle` で、城の中を走る区間は features の `castle` で作れます。雪山の見た目は `theme.frozen` / `theme.snowfall` と `scenery.cabins` / `scenery.snowmen`、木の種類 `snowpine` で作れます（例：`src/tracks/snowPeak.js`）。宇宙コースは `theme.space: true` で作れます（例：`src/tracks/starlightRoad.js`）。

仕掛け（`features`）には `ramp`（ジャンプ台）、`gap`（谷）、`cliff`（壁のない崖）、`bridge`（橋）、`tunnel`（トンネル）、`bank`（バンク）、`ruins`（遺跡）、`ice`（凍った路面）があります。地形・水辺・木はコースの形から自動で作られます。

雰囲気は `theme`（空・霧・草・道・柵の色、`bridgeStyle: "wood"` など）と `scenery`（木の種類 `treeTypes`、しげみ `bushes`、木の密度 `clearance` / `spread`）で変えられます。例は `src/tracks/jungleRuins.js` を参照してください。

`points` は閉じたスプラインとしてなめらかにつながり、1 点目がスタートラインになります。急すぎるカーブや、コース同士が近づきすぎる配置は避けてください。項目の詳しい説明は `src/tracks/index.js` にあります。

## ファイル構成

```
index.html / style.css   画面と HUD
src/main.js              起動・画面遷移・カメラ・メインループ
src/race.js              レース進行（参加者、カウントダウン、周回・順位、衝突）
src/track.js             コース定義の読み込み、路面の高さ・壁・足場の判定、座標変換、分かれ道の乗り移り
src/branch.js            分かれ道（枝道）
src/trackScene.js        コースの見た目（路面・壁・橋・トンネル・ジャンプ台・観客席・木・空）
src/terrain.js           コースに合わせた地形と水面の自動生成
src/kart.js              カートのモデルと物理（ドリフト、壁、スピン）
src/ai.js                NPC の運転
src/items.js             アイテムボックスとアイテム
src/hazards.js           邪魔してくる敵（クラッシャー・UFO・隕石・大雪玉・ファイアバー）
src/hud.js               順位・ラップ・アイテム枠・ミニマップ
src/audio.js             効果音（WebAudio で合成）
src/particles.js         火花・土ぼこり
src/tracks/              コース定義
```

参加者の名前と色は `src/race.js` の `RACERS`、むずかしさは `DIFFICULTIES` で変更できます。
