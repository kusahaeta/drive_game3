# NEARLINE — Urban Incident Drive

街中を自由に走りながら、横転トレーラー・対向車の車線逸脱・歩行者の飛び出しを回避する、ブラウザで動く3Dドライビングゲームのプロトタイプです。

## 起動方法

Node.js は不要です。プロジェクトのフォルダで以下を実行し、表示された URL（通常は `http://localhost:4173`）をブラウザで開いてください。

```bash
npm start
```

または:

```bash
python3 -m http.server 4173
```

初回の読み込み時だけ、Three.js とフォントを CDN から取得します。

## 操作

- `W` / `↑`: アクセル
- `S` / `↓`: ブレーキ・後退
- `A` / `D` / `←` / `→`: ステアリング
- `Space`: ハンドブレーキ
- `R`: 最初からやり直す

最初のルートを北（画面奥）へ進むと、3種類の事故イベントが順に発生します。接触せずに至近距離を抜けると `NEAR MISS` として高得点になります。

## 収録した要素

- 夜の街を手続き生成したフリー走行マップ
- 速度に応じて曲がりにくくなる車両挙動と追従カメラ
- 予兆付きの対向車逸脱、横転トレーラー、歩行者飛び出し
- 近接距離・接触を別々に扱うニアミス判定
- 雨、霧、街灯、車両ライト、エンジン音、警告音、ミニマップ、リスクHUD
